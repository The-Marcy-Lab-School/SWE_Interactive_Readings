The Missing Terminal

1. Why this exists

Before WSL (Windows Subsystem for Linux) existed, a Windows user who needed real Linux tools had two bad options. Option one: install a full virtual machine, like VirtualBox or VMware. That means running a whole second operating system inside the first one — its own multi-gigabyte disk, plus several GB of RAM tied up just to keep it running. Option two: dual-boot. Partition the hard drive, install Ubuntu next to Windows, and reboot the whole machine every time you switch from writing code to replying to email. Neither option was cheap. For years, they were the only real answers.

Microsoft's own developers hit this same wall, so often that in 2016 Microsoft teamed up with Canonical (the company behind Ubuntu) to build something new. It starts in about a second. It shares files directly with Windows. It costs nothing to leave running. That's WSL. It isn't a simulation of Linux commands, and it isn't a second computer pretending to be one. It's a real Linux kernel, running right alongside Windows on the same machine.

Where this is headed: once WSL is running, every other setup step in this fellowship works exactly as written — installing git, running python3, navigating a real file system. No Windows-specific workaround needed. This one step unlocks all the others.

3. Getting it installed

The entire install is one command, run from PowerShell or Windows Terminal opened as Administrator:

wsl --install

That one command downloads the WSL feature, installs a real Linux kernel, and sets Ubuntu as the default distro — all in one pass. When it finishes, Windows asks you to restart. The first time Ubuntu opens after that, it asks you to create a username and password. This login is separate from your Windows account, so write it down somewhere. You'll type it every time a command needs elevated permission (sudo) from here on.

Referring to the steps above: put them in the order they actually happen.

  • Open PowerShell or Windows Terminal as Administrator
  • Run wsl --install
  • Restart the computer when prompted
  • Create a Linux username and password on first launch
Need a hint?

Nothing about Ubuntu can happen until the feature itself is installed, and nothing about the feature finishes installing until after the restart.

6. Summary & reflection

WSL exists because Microsoft's own developers needed real Linux tools without paying for a full virtual machine or a dual boot. Now every Windows-based engineer in this fellowship gets that same real Linux environment for free, built right into Windows. wsl --install, a restart, and a username/password — that's the entire setup.
